# Lil Piggy illustrations

Drop the real artwork here, named after the mood. Each file replaces its vector
stand-in the moment it lands, so the set can arrive one file at a time.

    happy        proud        sad
    excited      curious      unhinged
                 suspicious

Any of `.png` `.webp` `.svg` `.jpg` `.gif` — first match wins, in that order.
A mood with no file keeps the vector, so there is never a broken image.

Square artwork works best; the component sets width and lets height follow.
